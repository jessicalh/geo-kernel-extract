Scope and authority
-------------------
This inventory was derived from the live Compute bodies, ConformationAtom
ownership banners, ConformationResult::WriteAllFeatures, OperationRunner's
fixed sequence, and the trajectory TimeSeries/Welford consumers.  Names are
serialized names, not proposed aliases.  "T1" always means the project's
Cartesian Levi-Civita dual, not a real-Y1m vector.

The live catalog contains 306 array specifications.  Exactly 178 carry an
explicit directional or load-bearing companion transformation contract;
python/tests/test_topology_sidecar.py and the static ledger below are
set-identical to those 178 names, with one standalone row per name.  The other
128 entries were inspected as invariant identity/topology, scalar science,
energy/charge/distance, tensor-norm, or non-directional availability data;
none is an unclassified vector, tensor, position, normal, or signed geometry.

Transformation symbols
----------------------
Q  : an arbitrary orthogonal 3x3 matrix, det(Q)=+1 proper or -1 improper
t  : translation
P  : polar vector,             v' = Q v                         (1o)
A  : axial vector,             a' = det(Q) Q a                  (1e)
X  : position,                 p' = Q p + t                     (affine)
T  : ordinary even rank two,   T' = Q T Q^T                     (0e+1e+2e)
S  : rotation-invariant scalar
PS : pseudoscalar,             s' = det(Q) s
ST : symmetric/traceless T; project PackFull9 T0 and T1 are structural zero
L  : calculator-defined local-frame quantity; its frame law is stated inline

For every ordinary T tensor, PackFull9 is
  [T0,T1_x,T1_y,T1_z,T2_m-2,T2_m-1,T2_m0,T2_m+1,T2_m+2].
T0 is invariant, T1 is AXIAL under improper Q, and native T2 is the isometric
five-component real-tesseral project basis.  "T1 structural zero" means the
Cartesian tensor is symmetric; "T0 structural zero" means it is traceless.

Per-frame NPY boundary
----------------------
FrameNpyEmitter::OnFrame calls the same ConformationResult::WriteAllFeatures as
static extraction.  Therefore every static name above is also the exact name
under frame_NNNNNN/.  Serialization acceptance must check at least one static
directory and one frame directory with numpy.load(..., allow_pickle=False),
including NaNs, masks, structural zeros, and sparse atom/ring/bond row identity.

Source-availability discipline for raw H5
-----------------------------------------

NaN-fill absent frames or suppress the group if no frame has the source.

* water/APBS/MOPAC optional groups correctly distinguish globally absent source.
