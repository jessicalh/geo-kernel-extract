## 1. Display modes

Key mechanisms:

- Capability gate: every `strip.*` mode is considered visible, non-panel, and non-panel-ref by `DisplayModeCapabilityFor()`; only six `static.*` modes have any capability entry (`static.bar.sequence`, `static.spectrum.power`, `static.curve.lag.animated`, `static.chord.coupling`, `static.fixed_freq`, `static.tensor`) [src/model/DisplayModeCapability.h:25](../src/model/DisplayModeCapability.h:25).
- User-facing candidate/active toggles require `hasVisibleSurface`; unsupported static modes are disabled in `SignalDisplayDialog` [src/app/SignalDisplayDialog.cpp:1191](../src/app/SignalDisplayDialog.cpp:1191), [src/app/SignalDisplayDialog.cpp:1399](../src/app/SignalDisplayDialog.cpp:1399).
- Static panel renderer dispatch is explicit and limited to a handful of `(storagePath, mode)` pairs [src/app/DashboardDisplayController.cpp:1597](../src/app/DashboardDisplayController.cpp:1597).
- `static.tensor` infrastructure exists, but the trigger is intentionally omitted/deferred [src/app/DashboardDisplayController.cpp:1675](../src/app/DashboardDisplayController.cpp:1675), [src/app/DashboardDisplayController.cpp:1748](../src/app/DashboardDisplayController.cpp:1748).
- Generic strip rendering always becomes `TemporalStripPanel` through `setTracks()` [src/app/StripStackWidget.cpp:401](../src/app/StripStackWidget.cpp:401). `SpectrumStripPanel` exists [src/app/StripStackWidget.cpp:420](../src/app/StripStackWidget.cpp:420), but `DashboardStripDock` clears spectrum tracks on every update [src/app/DashboardStripDock.cpp:313](../src/app/DashboardStripDock.cpp:313). Therefore `strip.spectrum` is not currently a spectrum renderer.
- Channel helpers define the real tensor/vector channel surfaces (`T0`, `T1`, `T2`, `component`, `x`, `y`, `z`, `magnitude`) [src/model/TrajectorySignalCatalog.cpp:53](../src/model/TrajectorySignalCatalog.cpp:53), [src/model/TrajectorySignalCatalog.cpp:62](../src/model/TrajectorySignalCatalog.cpp:62), [src/model/TrajectorySignalCatalog.cpp:71](../src/model/TrajectorySignalCatalog.cpp:71).
