# Encoding-frame walk — TensorNet adapt/suck + the 1o map (codex, read-only, 2026-06-07)

**1. Object Model**
The object model is very close to TensorNet’s rank-2 Cartesian state. `Mat3` is the raw 3x3 carrier, and `SphericalTensor` stores exactly `T0/T1/T2`: scalar trace/3, antisymmetric pseudovector, symmetric-traceless five-vector [Types.h](/shared/2026Thesis/nmr-shielding/src/Types.h:300). The implementation matches the TensorNet split `I/A/S`: `T0 = trace/3`, `T1 = [A_yz,A_zx,A_xy]`, and `T2` is an isometric real-spherical basis [Types.cpp](/shared/2026Thesis/nmr-shielding/src/Types.cpp:25).

Differences are mostly conventions, not mathematics: TensorNet works internally with rank-2 Cartesian tensors and decomposes when useful; this project persists the packed spherical layout `[T0,T1x,T1y,T1z,T2m...]` [Types.h](/shared/2026Thesis/nmr-shielding/src/Types.h:318). The project’s `T2` normalization and ordering are explicit and local [Types.cpp](/shared/2026Thesis/nmr-shielding/src/Types.cpp:46). Parity is not intrinsic to `SphericalTensor`; it lives in schema/metadata. For shielding tensors the frame is settled: `0e + 1e + 2e`, never `1o` [equivariant_encoding_review.md](/shared/2026Thesis/nmr-shielding/doc/emerging/equivariant_encoding_review.md:23).

**2. Kernels / Double-Feed**
The stable kernels are all low-order multipole objects in the expected sense.

BS emits a full packed shielding tensor after computing a finite-wire Biot-Savart field and forming `G_ab = -n_b B_a` [BiotSavartResult.cpp](/shared/2026Thesis/nmr-shielding/src/BiotSavartResult.cpp:228). HM integrates the dipolar kernel `3 rho_a rho_b/rho^5 - delta/rho^3`, then forms the same rank-1 shielding kernel and decomposes it [HaighMallionResult.cpp](/shared/2026Thesis/nmr-shielding/src/HaighMallionResult.cpp:70). Charge/EFG computes `E = q r/r^3` and `V = q(3rr/r^5 - I/r^3)` [CoulombResult.cpp](/shared/2026Thesis/nmr-shielding/src/CoulombResult.cpp:156); APBS and water keep `E` as a vector and emit EFG as T2-only after symmetrize/traceless projection [ApbsFieldResult.cpp](/shared/2026Thesis/nmr-shielding/src/ApbsFieldResult.cpp:99), [WaterFieldResult.cpp](/shared/2026Thesis/nmr-shielding/src/WaterFieldResult.cpp:70). Intended McConnell is `D(r)Q`, with `D=(3nn^T-I)/R^3`, and emits full even `0e+1e+2e` [mcconnell_structured_grounding.md](/shared/2026Thesis/nmr-shielding/doc/emerging/kernel_design/mcconnell_structured_grounding.md:46).

The attribution confound is real. An `l<=2` first steerable conv over raw geometry can relearn the same angular basis as Coulomb/EFG, McConnell, HM, ring-susceptibility, H-bond, and the low-rank ring-current summaries. BS/HM are less “one edge, one `1/r^3`” because BS uses finite wire segments and HM surface quadrature, but their emitted shielding tensors still land in the same `0/1/2` representation space. APBS/water are only trivially relearnable if the model also sees the solvent/grid/source charges; otherwise they are external field features. For Part 1, don’t double-feed fixed kernels into an `l<=2` conv if making attribution claims [equivariant_encoding_review.md](/shared/2026Thesis/nmr-shielding/doc/emerging/equivariant_encoding_review.md:25). For Part 2 fido prediction, double-feeding is acceptable if ablated [equivariant_encoding_review.md](/shared/2026Thesis/nmr-shielding/doc/emerging/equivariant_encoding_review.md:75).

**4. Radials**
The dominant physical radial is indeed the dipolar `1/r^3` tensor: Coulomb/EFG, water EFG, APBS EFG, HM, McConnell, H-bond, and several ring-style kernels use that skeleton. The E-field is `r/r^3` with magnitude `1/r^2`. But not everything is literally `1/r^3`: BS uses a finite wire-segment Biot-Savart formula [BiotSavartResult.cpp](/shared/2026Thesis/nmr-shielding/src/BiotSavartResult.cpp:31), pi-quadrupole uses `1/r^4` scalar plus `1/r^5,1/r^7,1/r^9` tensor terms [PiQuadrupoleResult.cpp](/shared/2026Thesis/nmr-shielding/src/PiQuadrupoleResult.cpp:75), and dispersion uses `1/r^6` / `1/r^8` with switching [DispersionResult.cpp](/shared/2026Thesis/nmr-shielding/src/DispersionResult.cpp:70).

The clean seam is model-side, not inside the C++ producers. The producers emit fixed physical channels. A learned radial should take raw neighbor/source geometry and include a fixed physical power-law channel plus a learned residual radial basis, exactly as the frame suggests [equivariant_encoding_review.md](/shared/2026Thesis/nmr-shielding/doc/emerging/equivariant_encoding_review.md:51). If you want per-source residual auditing, that needs extra plumbing; if you only want fido prediction, the SDK/model input boundary is enough.

**5. e3nn vs TensorNet**
TensorNet fits unusually well here because the project’s object model is already rank-2 Cartesian `Mat3` plus `0/1/2` decomposition. The physics family is capped at `l<=2` per single feature, so TensorNet’s cap is not a bug for the Four. Higher angular/body complexity would have to arrive through products and message passing, not native single-feature `l>2`.

e3nn still earns its place for Part 1: explicit irreps, parity bookkeeping, spherical harmonics, tensor products, mirror tests, and controlled `lmax` are the cleanest way to make the methods claim. The dragon changes deployment: the solution shift is `0e`, so full carry-`l=2` is justified for DFT-anchored Parts 1-2, not automatically for Part 3 scalar prediction [equivariant_encoding_review.md](/shared/2026Thesis/nmr-shielding/doc/emerging/equivariant_encoding_review.md:62).

**TensorNet Research**
TensorNet is Simeon & de Fabritiis, “Cartesian Tensor Representations for Efficient Learning of Molecular Potentials,” arXiv:2306.06482 / NeurIPS 2023. It is an `O(3)`-equivariant message-passing architecture using rank-2 Cartesian tensor atomic embeddings; feature mixing is done with 3x3 matrix products, and the tensor can be decomposed into scalar, skew/antisymmetric vector, and symmetric-traceless tensor parts. Primary sources: [arXiv](https://arxiv.org/abs/2306.06482), [NeurIPS PDF](https://proceedings.neurips.cc/paper_files/paper/2023/file/75c2ec5f98d7b2f50ad68033d2c07086-Paper-Conference.pdf).

There is a usable implementation in TorchMD-Net: the docs expose `torchmdnet.models.tensornet.TensorNet` with normal neural-potential knobs such as hidden channels, layers, radial basis, cutoffs, and neighbor limits [TorchMD-Net docs](https://torchmd-net.readthedocs.io/en/2.4.4/models.html). It is not a turnkey NMR shielding-tensor predictor; the output head and metadata discipline would be project work.

Reported strengths are exactly the ones relevant here: fewer parameters than higher-rank spherical tensor models, fewer message-passing steps, efficient tensorial features, and support for vector/tensor molecular quantities on top of potentials. e3nn is the broader framework: it provides explicit `O(3)` irreps, parity, spherical harmonics, and tensor products [e3nn arXiv](https://arxiv.org/abs/2207.09453), [e3nn docs](https://docs.e3nn.org/en/latest/index.html).

**Bottom Line**
The frame mostly names what the code already is: `Mat3 -> T0/T1/T2` is TensorNet-shaped, and the kernels are already low-order multipole features. The real changes are metadata and experimental hygiene: fix stale shielding `1o` labels to `1e`, keep real polar fields as `1o`, add a mirror/parity test, and avoid double-feeding kernels into an `l<=2` conv when claiming attribution. The cheap architectural win is a radial fixed-law-plus-residual seam. TensorNet is a genuinely good lightweight candidate for Parts 1-2 fido/tensor work; e3nn remains the better symmetry microscope. For Part 3, the dragon says do not let the tensor machinery outrun the scalar observable.
