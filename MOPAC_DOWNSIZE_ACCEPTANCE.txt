CALCULATOR CONTRACT AND CALL CONFIGURATION

MopacResult has no Dependencies() entry. In the existing fixed
OperationRunner order it remains gated by an attached
ChargeAssignmentResult, from which the runner supplies the exact topology
net charge. Dependencies remain an attach-time typed guardrail, not an
orchestration mechanism.

Compute materializes every direct and compatibility field on MopacResult and
sets only MopacResult-owned ConformationAtom fields. WriteFeatures does no
scientific computation or reconciliation; it only packs and writes stored
values. MopacCoulombResult and the McConnell bond-order channel continue to
read the typed ConformationAtom MOPAC surface. No other calculator's
scientific result is aggregated or projected by MopacResult.

The worker zero-initializes mopac_system, mozyme_state, and mopac_properties.
Zero-initialized state.numat=0 selects the Lewis-guess start. It invokes only:

  mozyme_scf(&system, &state, &properties)

The exact system configuration is:

  model=0                    PM7
  charge=<exact topology charge>
  spin=0
  epsilon=1.0
  natom_move=0               single point, no geometry optimization
  nlattice=0
  nlattice_move=0
  pressure=0.0
  tolerance=1.0
  max_time=7200 seconds

Coordinates are quantized in memory to the legacy writer's eight decimal
places so the physical input is unchanged without creating a .mop file.
There is no conventional-SCF substitution, convergence loosening, geometry
optimization, STATIC request, or polarizability calculation.

After a returned call, RAII always invokes destroy_mopac_properties and
destroy_mozyme_state. The returned data is copied and validated before any
ConformationAtom MOPAC field is committed.


COMPLETE 50-ARRAY EMIT INVENTORY

Notation:

  P = struct mopac_properties
  S = struct mozyme_state
  T = typed Protein topology
  N = atoms; B = topology bonds; C = retained compact pairs
  U = API-unique a<b sparse pairs; E = directed CSC entries
  W = P.ao_max_orbitals; O/V = occupied/virtual LMO counts

All floating arrays are float64 and all integer arrays are int32. Index
normalizations are stated explicitly; otherwise values are copied exactly.

Compatibility arrays retained from the previous schema:

  1. mopac_charges, shape (N)
     Source: P.charge, projected through the legacy F15.6 print precision.

  2. mopac_scalars, shape (N,4)
     Source: P.charge; s/p sums from the diagonal of P.atom_ao_density,
     interpreted with P.ao_orbitals and S.iorbs; compact valency from
     P.bond_index/P.bond_atom/P.bond_order after reproducing MOPAC's compact
     row ordering, first-six selection, F6.3 formatting, and >0.01 parser
     threshold. Atoms without p AOs carry mathematical zero as before.

  3. mopac_bond_orders, shape (C,3)
     Source: P.bond_index/P.bond_atom/P.bond_order. Reproduces the Fortran
     selection ordering, first six entries per atom, F6.3 projection, strict
     >0.01 retention, and unordered-pair maximum. Its native axis is the
     distinct mopac_compact_pair axis, not the API-U axis.

  4. mopac_bond_neighbors, shape (2C,4)
     Source: the same compact P CSC projection plus typed T bond indices;
     directed read-back sorted by decreasing order within source atom.

  5. mopac_global, shape (4)
     Source: P.heat at five decimal places and P.dipole xyz at three.

  6. mopac_atom_populations, shape (N,12)
     Source: P.charge; trace/s/p/d of P.atom_ao_density; live AO widths from
     P.ao_orbitals/S.iorbs; the diagonal and compact valencies from P CSC.
     The text-only f-shell and per-atom-dipole columns remain explicit NaN.

  7. mopac_atomic_orbital_populations, shape (N,9)
     Source: diagonal P.atom_ao_density in MOPAC s/px/py/pz/d order,
     projected through legacy F10.5 only through each live AO width.
     Non-existent per-atom AOs are explicit NaN.

  8. mopac_atomic_orbital_population_totals, shape (N,3)
     Source: sums of the individually F10.5-projected values in array 7,
     preserving the previous printed-table arithmetic and NaN masks.

  9. mopac_bond_valencies, shape (N)
     Source: diagonal entries of P.bond_order's CSC matrix, projected to
     three decimal places.

 10. mopac_bond_orders_unique, shape (U,8)
     Source: symmetric a<b entries from P.bond_index/P.bond_atom/
     P.bond_order. Each direction is first F6.3-projected, then max/mean are
     formed; T supplies the topology bond index. Text-only ALLBONDS count and
     printed-entry-index columns 4, 5, and 6 are NaN.

 11. mopac_topology_bond_orders_full, shape (B,8)
     Source: T bonds joined to the API-U P CSC projection. Missing sparse API
     pairs are explicit, the unique-pair index is on the API-U basis, and the
     text-only printed-entry-count column 7 is NaN.

STRUCTURAL N/A FIELDS

non-periodic, no-motion SCF and are documented in _catalog.py rather than
emitted as misleading zeros:

  P.freq, P.disp                       unavailable; no vibration calculation
  P.lattice_update, P.lattice_deriv    zero length because nlattice_move=0
  P.stress                             unavailable because nlattice=0

P.nerror and P.error_msg are control-plane fields. Any nonzero nerror aborts
before emission. Legacy columns lacking a struct source are NaN, never
defensive zeros.

FAILURE POLICY AND CRASH CONTAINMENT

If P.nerror != 0, all error_msg entries are copied into a worker failure
record. A missing required pointer, non-finite or dimensionally invalid data,
malformed/truncated protocol, nonzero worker status, or worker signal is also
a hard failure.

OperationRunner then sets RunResult.error and returns immediately. MopacResult
is not attached, no downstream requested-MOPAC result is computed, and the
normal success-output/.lgs path cannot run. skip_mopac remains a valid
extraction. No requested failure is converted to zeros or partial data.

The mopac2 mini-MOPAC was tested on dissociated H2. It corrupts its heap and
terminates with SIGABRT rather than returning nerror. MopacResult therefore
uses posix_spawn to run only mozyme_scf and struct copying in a fresh
nmr_mopac_worker, communicating over a versioned, bounded socket protocol.
The child disables core dumps. The parent reports signal 6 as a normal error
and remains alive; no partial MOPAC field is attached.
